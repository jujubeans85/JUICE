# Music-list preservation

**Music List Vault** (`preserve-music-lists`) applies automatically whenever the user requests a music list, playlist, crate, seed expansion, N5P, tracklist or revision.

It preserves exact versions, seeds and order; updates this canonical catalogue; rebuilds offline exports; and retains fresh replay launchers alongside original source URLs. A temporary YouTube queue is never the only saved record. The local personal-skill installation contains the instructions, canonical resource index and an offline replay-link helper.

The canonical data and app implementation remain here in `JUICE/main/CRATE_MAP`. The personal-skills platform owns the installed skill. Do not make a second music index or copy the installed skill into this public repository.
