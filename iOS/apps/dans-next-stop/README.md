# Dan’s Next Stop · Point Clare

[Open app](https://jujubeans85.github.io/ios/dans-next-stop/) · [Maintained source](https://github.com/jujubeans85/jujubeans85.github.io/tree/main/ios/dans-next-stop)

A playful travel companion for Dan: 24 destinations from/to Point Clare, public transport, driving and own-boat planning estimates, heart favourites, search and a home-screen installation guide.

## Source of truth

The complete app lives in `jujubeans85/jujubeans85.github.io/ios/dans-next-stop/`. This directory is a catalogue entry, not a duplicate implementation. GitHub Pages publishes the app directly. The earlier ChatGPT Site is a previous preview.

## iPhone

Open the app in Safari → Share → Add to Home Screen → keep Open as Web App enabled if shown → Add.

No login required. Favourites stay on the device. Offline use requires a successful first online load and retained browser storage. Live travel checks require internet. Times are planning estimates; unknown locations and untimed connections are explicitly marked.
