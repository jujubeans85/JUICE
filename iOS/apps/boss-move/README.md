# BOSS · Move mode

Open: https://jujubeans85.github.io/ios/boss-move/

Canonical source: https://github.com/jujubeans85/jujubeans85.github.io/tree/main/ios/boss-move

A focused five-step moving checklist with device-local saving, expandable notes, calendar reminder export, shareable snapshots, offline Home Screen support and small penguin celebrations. Vibrant portrait background with high-contrast tinted glass. Target date is editable; defaults to 18 November 2026.

Safari → Share → Add to Home Screen. Shared lists are snapshots, not live collaboration. Calendar alerts require importing the event or confirming a Siri reminder. This entry is a catalogue pointer; maintain source in the Pages repository.
