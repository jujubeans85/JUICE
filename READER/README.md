# JUICE Reader

A static paste-and-read page. This GitHub distribution uses a neutral sample; the original private Site is unchanged. Uses the browser Web Speech API; no speech backend, third-party scripts or analytics. Standalone mode makes no application API calls; a local dashboard installation may explicitly configure authenticated SSE. Only interface preferences are retained in localStorage. Pasted text remains in memory and is cleared on reload. The private Site's preloaded Mac repair prompt is intentionally excluded from this public source distribution.

Reader now has a distinct blue identity (#82baff), three quick choices drawn from distinct available voice families, preview playback, refresh and OS voice setup guidance. It cannot download/install device voices or guarantee Safari exposes every installed voice. No paid speech provider is configured.

The requested automatic intake accepts completed assistant responses with three or more paragraphs, stable conversation/message identity, duplicate suppression and a queue that preserves the current read. Loading never starts audio. Auto-load preference is also kept in localStorage. `intake.js` owns the shared rule. `integration/reader-client.js` provides the same-origin dashboard adapter; optional `JUICE_READER_CONFIG.eventsUrl` connects a same-origin authenticated SSE source. The working Mac checkout is unavailable in this environment, so the JC install is prepared, not performed.

`site-tools.js` adds a direct ChatGPT desktop path using the documented `document.modelContext.registerTool` API (with `navigator.modelContext` compatibility). Open the top-level page in the ChatGPT desktop built-in browser using a supported model/account. Two tools are registered: `juice_reader_status` checks preferences and receipts without returning editor text, and `juice_reader_receive_response` passes the exact final assistant response through the same `Inbox`. It returns a loaded/queued receipt, rejects ineligible messages and respects opt-out. Registration is labelled ready, a real tool invocation establishes contact, and successful intake establishes receipt. These states are independent of the dashboard connection. No registration or simulation proves a live user connection.

After the user has asked for automatic forwarding, the assistant can call the receive tool before posting the identical completed response. This is agent-mediated sending while the page is open, not a subscription to conversations or a token stream. ChatGPT's current official guide names Sol/Terra and the desktop browser, excludes Enterprise/Edu, and does not provide this page-based connection for iPhone/iPad. No native iOS conversation listener, remote MCP server or global hook has been installed. Actual live contact is pending the user opening the page in a supported desktop session. See [ChatGPT Site tools](https://learn.chatgpt.com/docs/webmcp).

`#read=<URL-encoded text>` supports explicit one-tap preload links; the fragment is removed immediately after parsing and is never an application HTTP query. This is a manual link, not a live subscription.

The distribution kit is generated by `python3 scripts/package-jc-kit.py` from these same authored assets and contains a checksum manifest, preserving a single source. A local JC installation is a pinned distribution of this release. The hosted and Mac origins remain separate unless a real authenticated connection is supplied. The module contract and Mac Codex handoff are in `dist/integration/`.

Voice availability, pronunciation and audio quality depend on the device. Voices marked online may transmit text to their provider. Foreground playback is the supported workflow; lock-screen/background playback is not promised. Pause cancels the current short utterance and resumes from the latest word boundary where available. Devices without boundary events repeat the current short passage. Generation and utterance identity guards ignore callbacks from cancelled speech.

References: [SpeechSynthesis](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesis), [SpeechSynthesisUtterance](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance), [SpeechSynthesisVoice.localService](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService).

`dist/` is authored source and the static deployment directory. No build or dependencies required. Syntax, assets and speech sequencing can be checked locally. Audible quality on the owner's iPhone/Mac requires that physical device; simulation cannot establish it.
